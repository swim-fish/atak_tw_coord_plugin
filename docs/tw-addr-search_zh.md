# 原生 Taiwan Address — 功能介紹

離線正向地址查詢已整合進 ATAK 原生座標輸入對話框；已移除舊版獨立的
**TW Addr Search** Tools 頁面。

## 搜尋前準備

外掛本身不內含地址資料。請開啟 **TW Coordinates**，點選資料集狀態／管理
項目，匯入邊界資料與適用縣市的 SQLite，或支援的 ZIP 資料包。詳見
[離線地址資料](tw-offline-addr_zh.md)。

查詢與正規化全在裝置端完成；外掛不要求 Android `INTERNET` 權限。

## 開啟 Address

1. 開啟 ATAK **Go To**。
2. 選擇 **Taiwan**。
3. 選擇第四個內部分頁 **Address（地址）**。

預設顯示一個完整地址輸入框；需要分別輸入或修正行政區時，可用模式切換
控制項展開四個結構化欄位。

## 完整地址模式

依平常方式輸入地址，例如：

```text
臺中市南屯區黎明路二段130號6樓之4
```

標準草稿會處理常見台灣地址差異：

- `台`／`臺`；
- 全形數字、空白與標點；
- 地址單位前的中文數字；
- 本機解析器支援的號、巷、弄、樓、室與附號格式。

縣市、行政區與道路／地名會使用資料集支援的最長前綴比對，不是只靠一條
大型正規表示式，因此不會在 `臺南市新市區` 或 `八德路` 的錯誤位置切開。

## 結構化模式

結構化模式有四個欄位：

1. 縣市；
2. 鄉鎮市區；
3. 道路或地名；
4. 其餘地址（段、巷、弄、號、樓、室與尚未分類的尾段）。

兩種模式是同一份 `AddressDraft` 的不同表示方式。反覆切換不可遺失或重複
未分類文字。編輯後會使舊查詢與候選清單失效，較慢的舊結果不能覆寫新草稿。

## 結果與候選選擇

- 唯一精確資料會解析成可交給 ATAK 確認的位置。
- 多筆可信資料不會自動選取。按**選擇結果**，比對縣市、行政區、道路／
  地名、門牌及其他區別資訊。
- 候選筆數有上限。選取資料只更新草稿／結果，不會移動地圖；ATAK 原生
  確認才會執行 Go To。
- 無效或查無資料時會顯示本地化狀態，也不會保留舊位置。
- 若沒有適用縣市資料集，依畫面提示開啟 **TW Coordinates** 管理資料；
  其他座標分頁仍可使用。

Settings 的 **Address search result order（地址搜尋結果排序）**可選擇依距離
或文字相似度排列候選。

## Convert Coordinate 與反向查詢

在地圖圖標詳細資料點選 **Coordinate**，開啟 **Taiwan** 後切到 **Address**。
Address 會非同步解析；台電、TWD97、TWD67 可立即使用。附近門牌只作為
描述，外掛會保留 ATAK 提供的精確 WGS84，不會吸附到門牌資料點。

Address **Auto Fill** 也遵守相同規則。**Clear** 只清除目前 Address 草稿並
取消待處理候選。唯讀流程可顯示地址，但不能編輯或選擇候選。

## 疑難排解

**沒有資料集／找不到資料：** 開啟 **TW Coordinates**，確認邊界資料與適用
縣市都已啟用。

**出現多筆相似資料：** 按**選擇結果**並比較行政區資訊；外掛刻意不猜測。

**編輯後似乎出現舊結果：** 必要時關閉後重開。生命週期防護會拒絕過期
callback，舊結果不可變成可確認的位置。

**需要管理容量或更新縣市：** 請參閱
[離線地址資料](tw-offline-addr_zh.md)。
