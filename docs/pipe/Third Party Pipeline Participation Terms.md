You must accept the terms below in order to use the Third Party Pipeline:

  

The Third Party Pipeline (TPP) provides an automated build, security scanning, and artifact generation capability for software submitted by external contributors.

Submission of materials to the TPP constitutes acceptance of the following conditions.

### 1\. Automated Processing

Submitted source code or build materials are processed automatically by the pipeline in order to generate software artifacts and conduct automated security analysis.

### 2\. Temporary Processing Environment

The TPP operates as an ephemeral build environment. Source code submitted to the pipeline is processed only for the duration required to complete the automated build and security scanning workflow.

The Government does not maintain persistent custody of submitted source code outside of transient processing required by the pipeline.

### 3\. Ownership

Submission of materials to the TPP does not transfer ownership of the underlying intellectual property to the United States Government.

Contributors retain ownership of their source code and associated intellectual property.

### 4\. System Monitoring

The TPP is a United States Government information system. Use of the system constitutes consent to monitoring, auditing, and security inspection for authorized purposes.

### 5\. Proprietary Material

Submitters are responsible for ensuring that any proprietary material submitted to the pipeline is properly marked and that they possess the authority to submit such materials.

Participation in the TPP does not create a separate proprietary information agreement with the United States Government.

### 6\. Limitation of Government Responsibility

The TPP is provided as a government service capability. The Government makes no representation regarding the confidentiality of submitted materials beyond protections provided by applicable law and government policy.
